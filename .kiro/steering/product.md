# Product Overview

**Cursed Relics** - An e-commerce platform for buying haunted and mystical items.

## Core Features

- Product catalog with categories (artifacts, charms, cursed dolls, stones)
- Shopping cart and checkout with Razorpay/Stripe payment integration
- User authentication (Firebase + backend JWT)
- Order management and tracking
- Admin panel for product and order management
- Email notifications for user actions

## User Roles

- **Customer**: Browse products, manage cart, place orders
- **Admin**: Full access to product/order/user management

## Payment Integration

- Razorpay (primary)
- Stripe (alternative)
- Backend handles payment verification and order creation
